# Stage 01, Unit 02: Centered Are You In Home Page

Status: completed.

Create the first visible app surface: a basic page that renders only a centered `Are You In?` heading.
- Route: the root homepage route.
- Content: a single `h1` with the exact text `Are You In?`.
- Layout: center the heading both horizontally and vertically in the viewport.
- Scope: no navigation, no extra copy, no CTA, and no secondary sections.

## Validation

- Acceptance: loading the root route shows a clean, minimal page with the `Are You In?` `h1` centered in the page.
- Verification: the page renders correctly at common desktop and mobile viewport sizes without requiring interaction.
