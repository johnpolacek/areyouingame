# Roadmap

This MVP plan starts with a hello-world-first greenfield build, then incrementally turns the source concept into a daily persistent shared simulation loop grounded in structured state, immutable history, and narrative memory.

## MVP Stages

- Stage 01: Hello World And Stack Lock
- Stage 02: Scaffold And Baseline App
- Stage 03: Daily Game Entry, Auth, And Player Creation
- Stage 04: Canonical State And Event History
- Stage 05: First Chat And Natural Language Action Loop
- Stage 06: Narrative Memory
- Stage 07: Daily Game Lifecycle And Recaps
- Stage 08: MVP Hardening And Commit Flow
