# Roadmap

This MVP plan starts with a hello-world-first greenfield build, then incrementally turns the source concept into a daily persistent shared simulation loop grounded in structured state, immutable history, and narrative memory.

## MVP Stages

- Stage 01: Hello World And Stack Lock
- Stage 02: Daily Game Entry And Auth
- Stage 03: Daily Player Creation
- Stage 04: First Chat And Natural Language Action Loop
- Stage 05: Canonical State, Event History, And Narrative Memory
- Stage 06: Daily Game Lifecycle And Live Public Activity
- Stage 07: MVP Hardening And Commit Flow
